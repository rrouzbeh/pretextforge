# Changelog

## Unreleased

- Focus the project on social-engineering data generation; remove claim extraction,
  detector replay, scoring, comparison commands and their example fixtures.
- Retain independent dataset validation, transcript audit packets and portable render
  caches. Update CLI documentation and CI for the generation-only workflow.
- Add a mostly benign five-day scenario with 500 users, 90 benign and 10 malicious
  scripted cases, plus routine support and file activity.
- Reject rendered agent text that changes the caller's manager to the agent's manager.
- Record local M4 authoring measurements and correct macOS memory reporting in the
  workload runner.
- Document architecture, reproducibility and validation results for external readers.

## 0.3.1

- Enforce profile loss/delay rules, lifecycle identities, scenario outcomes, ticket/file
  facts, published plan clocks and recovery-after-login checks independently.
- Reject contradictory utterances before publication; respect role, clause scope,
  negation and conditional promises in policy-critical claims and the rule baseline.
- Retry failed extraction with retained history, return failing CLI status for incomplete
  extraction and block incomplete releases. Validate whole-turn cache source bindings.
- Normalize action time zones before sorting; reject reserved IDs, phone aliases, blank
  identity fields, unsupported outcomes and malformed YAML mapping keys cleanly.
- Honor rendering styles, stabilize reuse order, correct scoring of unsupported holds,
  add 39 regressions and a reproducible 80-scenario sweep, and regenerate event outputs.

## 0.3.0

- Fix desk/employee phone collisions and derive speech, approval and recovery clocks
  from accepted wording, with explicit operational waits.
- Expand phrase banks and urgency contexts; shuffle recovery schedules independently
  of intent and add a replacement-device narrative holdout.
- Add variable background workloads, active-factor authentication, session/device/IP
  joins and reusable files with consistent download/share facts.
- Batch and reuse validated model utterances; retain explicit source-repair counts
  and recorded validation rejections.
- Classify current public utterances with typed speech-act tags and attach exact
  source quotes in code. Preserve grounded, arrival-ordered policy decisions.
- Replace old generated data/caches with fresh complete/degraded and control runs,
  frozen comparisons, offline examples and coherence regression checks.

## 0.2.0

- Add private typed turn plans, explicit local-model rendering, resumable content-addressed
  caches and generation from validated text with no inference/network calls.
- Reuse model responses for identical de-identified prefixes; keep expanded conversation
  entries, raw candidate attempts, model revisions and prompt/output digests auditable.
- Add quote-backed claim extraction and cached prefix-only procedural replay. Spoken
  approvals cannot replace ITSM verification. Extraction failures remain explicit.
- Add transcript audit packets, cache exports, frozen comparisons, attempt journals,
  held-out identity scenarios and real-model release validation scripts.
- Keep human review and new-family holdout status explicit; automated validation is
  not semantic proof or a human review substitute.

## 0.1.0

- Deterministic template generator, two attack stories and legitimate twins, correlated
  sources, answer keys, observation profiles, rule replay and a tested enterprise workload.
